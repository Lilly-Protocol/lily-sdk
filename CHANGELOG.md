# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2025-02-01

### Added

- Initial SDK release with typed clients for agents, wallets, payments, identity, and system.
- Fetch-based HTTP transport with retry support and timeout handling.
- Config resolution with validation and deep-freezing.
- Comprehensive test suite with 190+ tests across all modules.
